# Задача 01: Инициализация репозитория и настройка окружения

## Описание задачи
Базовая настройка структуры проекта, создание необходимых конфигурационных файлов для локальной разработки и Docker-окружения, а также подготовка документации.

## Выполненные действия

### 1. Структура проекта
Сформирована классическая структура Fullstack приложения (Monorepo подход):
```text
/workspace
├── backend/          # Django приложение
├── frontend/         # React приложение
├── docs/             # Документация проекта
├── docker-compose.yml
└── .env              # Переменные окружения
```

### 2. Настройка переменных окружения (.env)
Создан корневой файл `.env` для управления конфигурацией через Docker Compose.
**Принятые решения:**
- Вынесены порты (`BACKEND_PORT=8000`, `FRONTEND_PORT=3000`) для удобства локального запуска.
- Заданы надежные пароли по умолчанию для PostgreSQL и суперпользователя Django (`admin/admin` для демо, в продакшене требуется смена).
- Использованы стандартные имена переменных Django (`DJANGO_SETTINGS_MODULE`, `SECRET_KEY`).

### 3. Конфигурация Docker
Файл `docker-compose.yml` настроен для оркестрации трех сервисов:
- **db**: PostgreSQL 15. Аллоцирован том `pgdata` для сохранения данных между перезапусками.
- **backend**: Сборка из `./backend`. Зависит от базы данных. Команда запуска ожидает миграции.
- **frontend**: Сборка из `./frontend`. Проброшены порты для Hot Reload (разработка).

**Обоснование решений:**
- Использование `volumes` для базы данных критично, чтобы не терять данные при рестарте контейнеров.
- Разделение сетей (default network) позволяет сервисам общаться по именам (backend видит db по хосту `db`).

### 4. Backend (Django)
В папке `backend` реализована базовая конфигурация:
- `requirements.txt`: Добавлен `gunicorn` для production-сервера и `psycopg2-binary` для драйвера БД.
- `settings.py`: Настроено чтение переменных из окружения (`os.environ.get`), что позволяет безопасно деплоить приложение.
- `Dockerfile`: Многоступенчатая сборка (хотя в данном случае одноступенчатая достаточна для MVP) с установкой зависимостей и сборкой статики.

### 5. Frontend (React)
В папке `frontend` подготовлена основа:
- `package.json`: Основные зависимости (react, react-dom, react-router-dom, axios, antd).
- `Dockerfile`: Использование Node-образа, установка зависимостей, запуск dev-сервера на `0.0.0.0` для доступа извне контейнера.

### 6. Документация
Создан данный файл в папке `docs`, описывающий архитектуру и принятые решения на старте проекта.

## Статус
✅ Задача выполнена. Окружение готово к запуску команды `docker-compose up --build`.
