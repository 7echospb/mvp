# План задач MVP

## Правила выполнения

- Каждая задача должна занимать не более нескольких часов.
- Сначала выполняются задачи P0.
- P1 выполняются только после готовности сквозного сценария.
- P2 не должны блокировать демонстрацию.
- Все интеграции должны иметь демонстрационный резервный режим.
- После каждой задачи обновляется краткая документация.
